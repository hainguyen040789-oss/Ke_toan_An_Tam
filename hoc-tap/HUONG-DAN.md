# Gói "Giáo viên gia đình" – hướng dẫn sử dụng

Agent giáo viên dạy **Toán, Ngữ văn (Tiếng Việt), Tiếng Anh, Tự nhiên – Xã hội / Khoa học tự nhiên** cho 3 bé:
🐷 Heo Mập (lớp 2) · 🐐 Dê Ốm (lớp 6) · 🦖 Khủng Long (lớp 9) – TP.HCM, bộ Kết nối tri thức.

## Trong gói có gì

| File | Nội dung |
|---|---|
| `.claude/agents/giao-vien-gia-dinh.md` | Agent giáo viên (cách dạy, nguyên tắc sư phạm) |
| `hoc-tap/ho-so-hoc-sinh.md` | Hồ sơ, điểm mạnh/yếu và cách dạy riêng từng bé |
| `hoc-tap/lich-hoc.md` | Lịch học chi tiết 30 phút/ngày |
| `hoc-tap/thoi-khoa-bieu.pdf` | Thời khóa biểu để in dán tường |
| `hoc-tap/thoi-khoa-bieu.xlsx` | Thời khóa biểu dạng Excel để sửa |
| `hoc-tap/bai-lam/`, `hoc-tap/nhat-ky/` | Nơi lưu bài luyện và nhật ký học tập |

## Cài đặt

1. Giải nén vào thư mục dự án (giữ nguyên cấu trúc thư mục `.claude/` và `hoc-tap/`).
2. Mở Claude Code trong thư mục đó.
3. Nói chuyện bình thường, ví dụ:
   - "Ra 5 bài toán cộng trừ cho Heo Mập"
   - "Dê Ốm cần ôn phân số"
   - "Chấm bài văn nghị luận của Khủng Long" (dán bài vào)
   - "Hôm nay thứ 6, Khủng Long học gì?"

Muốn đổi lịch hoặc hồ sơ: nhắn yêu cầu cho Claude, hoặc sửa trực tiếp file `.md`.
